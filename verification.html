Primary documents only

Statute on congress.gov, the rule on federalregister.gov, agency guidance on cms.gov, medicaid.gov and dhcs.ca.gov, tax material on irs.gov. News coverage is never the source of a value.

Blank beats wrong

If two official sources conflict, both are shown and the row is flagged. If none states the value, the cell stays empty.

A row marked “verified” means the value matches the linked document. It does not mean the reader qualifies.

Method

  1. Collect the primary document. Statute, regulation, Federal Register notice, agency letter, or official table — not a summary of it.
  2. Extract one value per row. Each row of every table is a single claim with a single source id.
  3. Cross-check. Where two agencies both speak, the values are compared. A difference is flagged, not averaged.
  4. Leave blanks. No official value means no value in the cell.
  5. Guard the build. The generator refuses to publish a row with a missing source, a verified row with no value, or an unverified row that carries one.

Reproduce: python3 scripts/build_core.py && python3 scripts/check_core.py && python3 scripts/check_links.py

The data file is data/core.json; the generator is scripts/build_core.py.

Limits of this review

  • It is a document review, not a legal opinion. Only a county eligibility worker, an administrative law judge, or a court can decide a specific case.
  • Personal facts are missing. Age, household size, county, exact income, filing status, and current coverage were not supplied, so no personal eligibility determination is made.
  • Guidance can change. CMS and DHCS can issue sub-regulatory guidance at any time; the source register is dated so a reader can see the vintage.
  • Links can rot. scripts/check_links.py validates internal links and anchors; official external URLs were checked when the register was compiled.

Report a conflict by citing the flag ID and the official document. Do not edit a value without a source.
